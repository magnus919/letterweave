# Code and dataset licensing

This original implementation is MIT licensed by the repository [LICENSE](../LICENSE), copyright 2026 Magnus. No upstream implementation or corpus was copied into it. The upstream generator's MIT declaration does not by itself license this project's generated data or provider judgments.

Fresh synthetic data is intended to receive a separate MIT license after applicable generation/review terms and public redistribution rights are resolved. Private synthetic pilots now exist; no public corpus has been released and no dataset license file claims that these private artifacts are already cleared for redistribution. Fixtures are software test artifacts, never the corpus.

The verified private route was Nous Portal's OpenAI-compatible API with exact `openai/gpt-6.1-sol`, using existing paid access. Private generation was explicitly approved. [Current terms review](current-provider-release-terms.md) records the official clauses and unresolved upstream applicability. Consumer Codex subscription access does not establish API credit. Provider-reported subscription cost zero does not establish free or attributable invoice cost.

Before public release, record the account/service terms applicable to the actual route, their effective/access dates, and official evidence covering redistribution of synthetic text, labels and review judgments. Output ownership alone does not resolve use restrictions. This project does not train or distribute a model. Do not accept new terms or obtain grants automatically.

Include a separate dataset MIT license naming the released corpus/version and rights holder, a completed data card, provenance and exclusions. Determine the publishable scope of raw outputs and judgments separately; no credentials, private settings, private execution paths or hidden reasoning belong in a public bundle. Publication approval remains separate from private generation and automated review.
